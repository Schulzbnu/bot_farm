# Roadmap v0 → v1

## v0.1 (Fundação)
- Estrutura de projeto
- Leitor de tela + detector HP/Mana básico
- Executor de hotkeys com fila
- UI mínima (start/stop + status)

## v0.2 (Loop jogável)
- Healing funcional
- Auto spells
- Primeira versão de cavehunt por waypoints

## v0.3 (Economia)
- Refill com regras de estoque
- Depot por lista de itens
- Logs estruturados e replay de sessão

## v1.0 (MVP estável)
- Perfis por personagem
- Fluxos completos: hunt → refill → depot → hunt
- Empacotamento para uso simples
- Checklist de confiabilidade (crash recovery + watchdog)

## Critérios de aceite do MVP
- Rodar 4h sem travar em cenário de teste
- Recuperar automaticamente de 3 falhas simuladas
- Troca de perfil sem reiniciar aplicação
